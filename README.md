A static, read-only make.fun client: the bounty board with each bounty's live pot, entry fee, time left and entries; a bounty page with its brief, reward table and dates; its leaderboard; and public profiles — every surface on live make.fun API data, with ETag revalidation, a paginated board and one persistent shell. No framework, no build step, ~37 KB gzipped on first load.

## Run it

```sh
node serve.ts # serves app/ on http://localhost:8080
```
