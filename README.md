A static, read-only make.fun client built from plain ES modules and CSS, with no framework and no build step. It shows the bounty board with each bounty's live pot, entry fee, time left and entry count, along with a bounty page, a leaderboard and public profiles, all read from make.fun's public API. Screenshots of the main views are in `screenshots/`.

## Run it

```sh
node serve.ts
```

This serves `app/` on http://localhost:8080.
